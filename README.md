# Laboratórios de Programação Orientada a Objetos (POO)

Este repositório reúne os projetos e atividades práticas desenvolvidos ao longo da disciplina de POO. O objetivo dos projetos é consolidar o aprendizado nos pilares da orientação a objetos e boas práticas de desenvolvimento em Java.

## 🛠️ Conceitos Trabalhados
- Abstração e Encapsulamento
- Herança e Interface
- Polimorfismo
- Tratamento de Exceções
- Estruturas de Dados e Coleções (Lists, Maps)

## 📁 Projetos Incluídos
- **Sistema de Ingressos:** Modelagem de tipos de ingressos utilizando herança e polimorfismo.
- **Jogo da Forca:** Aplicação interativa em console aplicando lógica de jogo orientada a objetos.
